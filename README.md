## Project Description
This project presents an interactive stock market dashboard developed using R Shiny. It retrieves historical stock prices from Yahoo Finance and provides tools to explore price movements, technical indicators, and trading signals.

## Dashboard Features
- Stock selection and custom date ranges
- Daily, weekly, and monthly price analysis
- Line, area, and candlestick charts
- Adjustable short-term and long-term moving averages
- Relative Strength Index (RSI)
- Moving Average Convergence Divergence (MACD)
- Buy, Sell, and Hold trading signals
- Recent signal changes displayed in a table

## Tools and Libraries
R, Shiny, ggplot2, quantmod, TTR, dplyr, and xts.

## Running the Application
1. Open the project in RStudio or Posit Cloud.
2. Install the required R packages.
3. Open the `app.R` script.
4. Select Run App.
